# PDF 灰底修正

PowerPoint 匯出的 PDF，用 Mac 的「預覽程式」打開時底色變成灰色？把檔案丟進這個網頁，就能下載一份不管用什麼軟體開、拿去印都一樣的修正版。

## 使用方式

1. 打開網頁，把 PDF 拖進虛線框，或按「選擇檔案」（可以一次選多個）。
2. 對照「修正前／修正後」預覽。修正前是模擬 Mac 預覽程式看到的樣子。
3. 按「下載修正版」，檔名會加上「_修正版」。

## 為什麼會變灰

PowerPoint 存 PDF 時，會把設了透明度的圖片（例如底紋、緞帶）先乘上黑色再存，並在圖片的透明遮罩（SMask）裡註記 `/Matte`，請閱讀軟體打開時還原。瀏覽器和 Acrobat 會還原；macOS 的「預覽程式」不會，於是直接顯示壓暗後的顏色，看起來就像蓋了一層灰。

## 修正方式

對每張帶 `/Matte` 註記的圖片：

- 依透明度把顏色算回原值：`c = m + (c′ − m) / α`
- 用無損的 Flate 壓縮存回去，再移除 `/Matte`
- 幾乎全透明的邊緣像素改用鄰近像素的顏色，避免某些閱讀軟體出現暗邊

文字、字型、版面、頁面大小和其他圖片都不會改動。

## 隱私

所有處理都在你的瀏覽器裡完成，檔案不會上傳到任何伺服器。網頁只會從 CDN 載入下面列出的程式庫和字型，所以需要網路連線。

## 限制

- 只處理 `/Matte` 造成的灰底。如果灰色是設計本身的顏色、整頁是掃描圖，或檔案有加密，都不會改動。
- 支援 8 位元的 RGB、灰階、CMYK 圖片；壓縮格式支援 Flate 和 JPEG（JPEG 限 RGB 或灰階）。
